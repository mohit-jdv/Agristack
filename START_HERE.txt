AGRISTACK - FIXED DEMO PROJECT

IMPORTANT:
This ZIP contains the actual Next.js AgriStack application at its ROOT.
Do not run npm commands from a wrapper/workspace folder.

Windows PowerShell:
1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   npm install
4. Run:
   npm run dev
5. Open:
   http://localhost:8080

Demo mode is the default. Supabase credentials are NOT required for the SIH demo.

Useful checks:
   npm run typecheck
   npm run demo:simulate

The existing KisanSetu recommendation engine is preserved and the queue/token,
admin, ETA, and notification demo layer is included.
